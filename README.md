## About

I'm a Software Engineer with a background in **frontend and backend development** and a Master's focus in **Computer Networks, Cybersecurity, Cloud and Automation** at Sorbonne Université.

My current direction is **DevOps and Cloud Engineering**, with a particular interest in infrastructure automation, containerized systems, CI/CD, networking, security, and observability.

I enjoy understanding systems from the application layer down to the infrastructure and network layer, then turning that understanding into reproducible and automated solutions.
